README.md 파일에 본 프로젝트의 정체성에 대해 기록한다. 아래 사항들을 지키며 본 프로젝트를 진행한다.

본 프로젝트를 진행할 때는 먼저 깊게 생각하고 진행한다.

- 본 프로젝트는 쉬운 정보 변환 솔루션의 결과를 다양한 지표로 분석하기 위해 제작하고 있다.
- 프로그램을 실행하면 본 프로젝트에서 분석할 수 있는 다양한 종류의 지표 종류를 예쁘게 나열해서 보여 준다.
- md 디렉토리를 따로 구성해 본 프로젝트를 진행하는데 필요한 다양한 md파일들을 모두 넣어 관리한다. 단, readme.md 는 제외.
- 본 프로젝트에서 다룰 index의 종류와 설명은 indexes.md 파일에 모두 기록한다.
- 본 프로젝트는 python으로 구성한다.
- 가상환경을 구성해 진행해야 한다면 이를 위한 requirement를 다루는 환경을 구성하라. 가상 환경을 구성한다면 가상환경 구동 및 필요 라이브러리 설치 관련된 내용을 readme.md에 기록하라.
- 특정 index에 대해 작업이 진행되면 해당 index 이름으로 git branch를 생성하여 진행한다.
- 기본적으로 프로그램이 구동되면 문장을 입력 받는다. 이에 대해 한글 / 영문을 구분하여 현재 프로그램이 처리할 수 있는 모든 index값을 산출한다. 하지만, 특정 옵션을 입력하면 특정 index 값만 출력한다.
- index 별로 .py 파일을 따로 구성하며, 전체 실행 .py 파일에서는 이를 라이브러리로 불러와 구동할 수 있도록 한다.
- 팀 개발 가이드에 있는 개발 가이드에 준수하며 프로젝트를 진행한다.
